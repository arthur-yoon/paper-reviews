# A Dual-Dimensional LLM Framework for Automated Item Incidental Content Similarity Analysis in Large-Scale Assessments

## 핵심 아이디어 한 줄 요약
기존의 텍스트 유사도 지표(BLEU, 코사인 유사도)가 놓치던 시험 문제들의 맥락적·구조적 중복(인시던탈 콘텐츠)을 포착하기 위해, 구조적 분해와 의미적 관련성을 두 축으로 활용하는 LLM 기반 이중 차원 프레임워크(AISA)를 제안하여, 시험 문제 은행의 품질 관리와 적응형 테스트(CAT)의 정합성을 동시에 높인다는 것이다.

## 구현 설명
이 논문의 핵심은 '유사도'를 단순히 단어 겹침으로 보지 않고, **구조(Structure)**와 **의미(Semantics)**라는 두 가지 독립된 차원으로 분리해 측정하는 것이다. 이를 개념적으로 구현한다면 다음과 같은 단계로 단순화할 수 있다.

1.  **입력 데이터 준비**: 대규모 평가에 사용되는 시험 문제(Item) 목록과 각 문제의 정답 및 해설 데이터를 준비한다.
2.  **LLM 프롬프트 설계 (이중 차원 분해)**:
    *   **차원 1: 구조적 분해 (Structured Decomposition)**: LLM에게 각 시험 문제를 문법적 구조, 논리 전개 순서, 조건 제시 방식 등 '형식적 뼈대'를 추출하도록 지시한다. 이 과정에서는 구체적인 단어 내용보다는 문제의 '틀(Frame)'에 초점을 맞춘다.
    *   **차원 2: 의미적 관련성 (Semantic Relatedness)**: LLM에게 문제의 배경 설정(Context), 사용되는 용어의 뉘앙스, 문제의 핵심 의도(Intent)를 추상화한 의미 벡터나 설명을 생성하도록 지시한다. 이는 단어 자체보다 '말하려는 뜻'에 가깝다.
3.  **유사도 점수 계산**:
    *   추출된 '구조적 뼈대'들끼리, '의미적 추상화'들끼리 각각 유사도를 계산한다.
    *   두 점수를 조합하여 최종적인 **AISA 유사도 지표**를 산출한다. 예를 들어, 구조가 비슷하고 의미도 비슷하면 높은 유사도 점수를 받는다.
4.  **적응형 테스트(CAT) 적용 로직**:
    *   기존의 CAT 알고리즘은 문제 선택 시 정보량(Informativeness)을 최대화하는 것을 목적으로 한다.
    *   이 프레임워크를 적용하면, 문제 선택 시 **AISA 유사도 제약 조건**을 추가한다. 즉, 이전에 이미 응시자에게 제시된 문제들과 구조적/의미적으로 너무 비슷한 문제를 선택할 때 페널티를 부과하거나, 일정 임계값 이하의 유사도만 가진 후보 문제군에서만 다음 문제를 선택하도록 필터링하는 로직을 구현한다.

## 실행 방법과 예상 출력
**실행 방법:**
1.  모의 시험 문제 은행(예: 수학, 영어 문법 등)을 생성한다.
2.  해당 문제들을 AISA 프레임워크에 투입하여, 문제 쌍(Problem Pair) 간의 유사도 행렬(Matrix)을 생성한다.
3.  두 가지 시나리오로 모의 테스트를 진행한다.
    *   **시나리오 A (기존 방식)**: BLEU 또는 코사인 유사도 기반의 중복 제약을 적용한 CAT.
    *   **시나리오 B (AISA 방식)**: LLM 기반 구조/의미 유사도 제약을 적용한 CAT.
4.  동일한 모의 응시자 집단(또는 시뮬레이션된 능력 분포)을 두 시나리오에 통과시켜 성능을 비교한다.

**예상 출력:**
1.  **유사도 분포 차트**: 기존 텍스트 기반 지표는 표면적으로 단어가 겹치는 경우만 높은 점수를 주는 반면, AISA는 단어는 다르지만 문제 구조나 맥락이 유사한 경우에도 높은 유사도 점수를 부여하는 분포를 확인할 수 있다.
2.  **심리측정학적 검증 결과**:
    *   AISA 기반 유사도 지표가 '구성 무관한 국소적 의존성(Construct-irrelevant local dependence)' 지수와의 상관계수가 기존 지표보다 높게 나타남. 이는 LLM이 실제 시험장에서 응시자가 느끼는 '이 문제들, 비슷한 거 아냐?'라는 인식을 더 잘 포착한다는 의미이다.
    *   시험 문제 매개변수(Item parameters) 군집 분석 시, AISA 기반 군집이 기존 텍스트 기반 군집보다 더 일관성(coherence)이 높아 보임.
3.  **CAT 성능 비교 결과**:
    *   **추정 안정성(Stability)**: AISA 제약을 적용한 그룹에서 응시자 능력 추정값의 표준 오차가 더 작게 나옴.
    *   **편향(Bias)**: 특정 유형의 문제(예: 특정 맥락의 문제)에만 반복적으로 노출되는 편향이 감소함.
    *   **효율성 효율(Efficiency)**: 문제 수 증가 폭이 기존 방식과 비교해 미미함(Minimal efficiency trade-offs)에도 불구하고 위 두 가지 지표가 개선됨.

## 한계
1.  **추론 비용 및 속도**: BLEU나 코사인 유사도는 계산 복잡도가 낮아 실시간 처리가 용이하지만, LLM 기반 프레임워크는 문제 쌍마다 또는 문제 은행 전체에 대해 LLM 추론을 수행해야 하거나, 중간 단계의 추상화 벡터를 생성해야 하므로 계산 비용과 시간이 훨씬 많이 소요된다. 대규모 시험 문제 은행(수천~수만 개)을 실시간으로 처리해야 하는 프로덕션 환경에서는 이 지연이 문제가 될 수 있다.
2.  **LLM의 일관성 및 재현성**: 동일한 프롬프트와 데이터로 반복 실행해도 LLM의 출력(구조 분해 결과나 의미 추상화)이 미세하게 달라질 수 있다. 이는 최종 유사도 점수의 변동성을 유발하여, 시험의 공정성이나 객관성을 요구하는 고차원 평가에서는 신뢰도 문제가 될 수 있다.
3.  **도메인 특화 지식의 편향**: LLM이 학습된 데이터에 따라 특정 학문 분야나 언어의 맥락을 과도하게 일반화하거나, 반대로 특정 세부 분야의 고유한 구조적 특징을 놓칠 수 있다. 모든 시험 영역(예: 순수 수학의 논리 구조 vs. 문학의 주제 의식)에 대해 동일한 '구조'와 '의미' 정의가 적절하게 적용되는지 확인해야 한다.
4.  **검증의 복잡성**: '구조적 유사도'와 '의미적 관련성'의 적정 비중(weight)을 정하는 것은 주관적 판단이 개입될 수 있으며, 이 파라미터 설정에 따라 CAT의 성능이 크게 달라질 수 있어, 새로운 시험 영역에 적용할 때마다 세밀한 튜닝이 요구된다.
